# Princess-Maker-Children-of-Revelation-AssetBundle-Decrypt

A Python tool to decrypt AssetBundle for **Princess Maker: Children of Revelation (プリンセスメーカー 預言の子供たち)**.

## 安裝依賴 (Installation)

```bash
pip install pycryptodome
```

## 解密 (Decryption)
```bash
python decrypt_bundle.py dec in.enc out.bundle
```

## 加密 (Encryption) (no need)
```bash
python decrypt_bundle.py enc in.bundle out.enc original.enc
```
